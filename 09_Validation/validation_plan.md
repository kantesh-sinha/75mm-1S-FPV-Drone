# 09 — Validation

Verification asks whether the implementation satisfies technical requirements. Validation asks whether the complete system is suitable for the intended mission.

## V1 questions
1. Can it operate indoors as intended?
2. Can it perform controlled light outdoor flight in suitable conditions?
3. Is the radio link suitable for the intended test environment?
4. Is the analog FPV link usable?
5. What flight time is actually achieved?
6. Are temperatures and electrical behavior acceptable?
7. Does behavior remain predictable across repeated flights?

## Measurements
- hover behavior
- flight time
- battery voltage before/after
- current consumption where measurable
- motor/FC/VTX temperature observations
- radio/video issues
- failures and corrective actions

No performance result is final until recorded from the physical system.
