# CLI Baseline

Keep a versioned text export of the final configuration in this directory after the physical build is configured.

Recommended records:
- version.txt
- diff_all.txt
- status.txt
- resource.txt
- serial.txt
- final receiver/failsafe settings
- motor protocol and motor mapping

Betaflight's CLI supports diff, dump, status, resource, serial and motor-related commands. Exact output is version-specific.

Never present an example CLI dump as the actual drone configuration.
