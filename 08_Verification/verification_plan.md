# Verification Plan

Verification demonstrates that implemented functions match technical requirements.

## Test levels
Level 1 — Static inspection: part identity, wiring, polarity, mechanical clearance.

Level 2 — Powered bench: FC boot, sensors, receiver, video, motor outputs.

Level 3 — Controlled system: arming, failsafe, hover.

## Pass criteria
A test passes only when:
- the expected condition is explicitly defined,
- the observed result is recorded,
- the hardware/firmware revision is recorded,
- the result is repeatable or the limitation is documented.

Test results are stored separately from test procedures.
