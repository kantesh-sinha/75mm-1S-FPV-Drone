# Design Decisions

| Decision | Choice | Reason | Revisit when |
|---|---|---|---|
| DD-001 | 1S | Lightweight and accessible | Flight data shows insufficient power |
| DD-002 | 75 mm | Tiny-whoop ecosystem | Mission changes |
| DD-003 | AIO FC + separate VTX | Compact control electronics while preserving video subsystem visibility | Weight/space becomes limiting |
| DD-004 | Integrated Serial ELRS | Fewer parts/wires | Receiver limitation appears |
| DD-005 | Analog video | Low complexity and visible signal chain | Video requirement changes |
| DD-006 | 0802 ~22K | Target propulsion class | Thermal/current measurements disagree |
| DD-007 | 40 mm 3-blade | Frozen V1 test configuration | Propulsion experiment begins |
| DD-008 | Commercial frame | Keeps scope on electronics | Mechanical requirement changes |

Community evidence identifies plausible configurations; it does not substitute for measured performance.
