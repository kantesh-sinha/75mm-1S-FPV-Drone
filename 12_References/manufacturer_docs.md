# 12 — References

Primary sources to verify before assembly:

- BETAFPV F4 1S 5A AIO Flight Controller, Serial ELRS documentation
- BETAFPV support documentation for the exact FC hardware/gyro/firmware revision
- Caddx Ant Nano documentation
- AKK Nano3 documentation for the exact purchased revision
- Motor manufacturer datasheet for the exact 0802 22,000 KV motor
- Battery specification for the exact 1S 450 mAh BT2.0 pack
- Selected frame manufacturer's dimensional/mounting documentation

## Source discipline

Manufacturer documentation is preferred for pinout, voltage/current limits, mounting pattern, firmware target, connector type and electrical compatibility.

Community builds and marketplace listings are supporting evidence, not the sole source for critical electrical specifications.
