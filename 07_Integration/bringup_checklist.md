# Bring-up Checklist

### Power
- [ ] Visual inspection
- [ ] Continuity check
- [ ] Battery voltage measured
- [ ] FC powers without abnormal heating

### Flight controller
- [ ] USB connection
- [ ] Correct board target
- [ ] Gyro detected
- [ ] Accelerometer detected
- [ ] Orientation correct

### Receiver
- [ ] ELRS bound
- [ ] Channels correct
- [ ] Arm switch correct
- [ ] Failsafe tested

### Motors
- [ ] M1 correct
- [ ] M2 correct
- [ ] M3 correct
- [ ] M4 correct
- [ ] Direction correct
- [ ] Props still removed during bench tests

### Video
- [ ] Camera image
- [ ] OSD
- [ ] VTX output
- [ ] SmartAudio if supported
