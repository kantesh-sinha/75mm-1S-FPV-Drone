# Lessons Learned

## 1. Concept drawings are not schematics
A generated wiring image communicates intent but must be checked against manufacturer documentation and the physical board.

## 2. Hardware revision matters
The same product family can contain different gyro, receiver, UART and firmware-target configurations.

## 3. Keep design status explicit
Use DESIGNED, VERIFIED and MEASURED.

## 4. Separate verification from validation
Bench tests establish technical correctness; flight testing establishes whether the integrated system meets the intended mission.

## 5. Preserve evidence
Keep configuration exports, photographs, logs, measurements and failed-test records rather than documenting only the final state.
